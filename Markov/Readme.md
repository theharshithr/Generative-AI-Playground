# Day 1: Markov Chain Text Generator

## Overview
A web-based text generator using Markov chains to create probabilistic text based on training data.

## Concepts Learned
- Markov chains and state transitions
- N-gram language models
- Tokenization techniques
- Probability distributions in text

## Features
- Adjustable n-gram order (1-5)
- Multiple sample texts
- Real-time statistics
- Interactive web interface

## How to Use
1. Open index.html in your browser
2. Enter training text or use samples
3. Adjust order and length parameters
4. Train the model
5. Generate new text
